This is a placeholder post to show how the blog is structured — feel free to edit or delete it.

Posts live in the `_posts/` folder as Markdown files, named `YYYY-MM-DD-title.md`. Each one starts with a short front-matter block (the part between `---` lines) setting the `layout`, `title`, and `date`, and everything below that is written in plain Markdown — headings, **bold**, *italics*, links, lists, and so on.

## How to add a new post

1. Create a new file in `_posts/`, named with today's date and a short slug, e.g. `2026-09-20-fundraising-in-a-tight-market.md`.
2. Add the front matter block at the top (copy this post's as a starting point).
3. Write the post body in Markdown below it.
4. Commit it to the repository — GitHub Pages will automatically rebuild the site and the post will appear on the [Blog page](/blog/), newest first.

No other files need to change — the blog listing page picks up every post automatically.
